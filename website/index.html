Why Lumina

More than a download manager.

A download manager fetches files. Lumina does that, and a few things on top.

  1. It plays before it keeps.

    Paste a link and press Play. It starts at once, with nothing saved to your disk. Press Download only if you want to keep it.

  2. It is a real player.

    Music and video in one player, with synced lyrics, volume up to 200%, and every track brought to a similar loudness. Your downloads are already in it.

  3. It says what is happening.

    Saving to disk, reconnecting, waiting for the network: plain words and a calm colour, not “error 22”. A download carries on from where it stopped, even after you quit.

  4. It copes with awkward links.

    Over 1,300 video and music sites, plain files, stream links, torrents and magnet links. A built-in browser with an ad and tracker shield covers the pages that make you click through.

  5. It goes where you watch.

    Share your library to a television over your home network, copy it to a USB drive in a TV-friendly format, or use the Android app.

  6. It stays on your computer.

    No account and no sign-up. Links are read and files are kept on your own PC, in folders you choose.

    Where it stands

    Early, public, and honest about it.

    Version 1.1 is the first release on GitHub. It works, and parts of it are still being proven. Here is the plain picture, as of the 1.1.0 release.

    Working and checked

    • Many kinds of links. Direct files, zip archives, HLS and DASH streams, archive.org items, torrent files and magnet links, tried on 14 kinds of public test links.
    • Play without downloading. Plain files, WebM, MP3, HLS and DASH streams, with seeking.
    • Keeping progress. Quitting, a dropped connection or a full disk no longer throws a download away.
    • Staying up. If its window crashes, Lumina brings it back and your downloads keep running.

    Still being proven

    • The installers on other PCs. Built and checked, but this is the first public release, so expect rough edges.
    • Sites that want a sign-in. Some, such as YouTube at times, ask you to sign in under Settings first.
    • DASH streams can take about ten seconds to open.
    • Sleep and wake in the middle of a download has not been tried on a real PC yet.
    • The Android app has been used on one device and an emulator.

    What we want to do next

    • Use more than one network at once, when you have more than one connection.
    • Signed installers, so Windows stops warning on install.
    • Linux and macOS builds.
    • Better lyrics matching and display in the Android app.
    • A calmer, clearer queue, a step at a time.

    These are things we want to do, not promises, and they have no dates.

    Questions

    Good to know.

    Free and open.

    The desktop app is MIT licensed and the Android app is GPL-3.0. Read the code, and report problems.

    It respects limits.

    Lumina does not break copy protection, and it does not try to get around a site’s sign-in or your network’s blocks. If it can’t read a link, it says why.

    Use it fairly.

    Please use it for media you have the right to keep.

    Is Lumina really free?

    Yes. There is no payment, no account and no advertising. The source is on GitHub.

    Which sites does it work with?

    Over 1,300 video and music sites, through the open-source yt-dlp engine that Lumina keeps up to date, plus plain file links, stream links, torrent files and magnet links. Sites change often, so one that works today can break tomorrow until the engine catches up.

    Can it download anything?

    No. Use it for media you have the right to keep. Lumina will not download copy-protected (DRM) content, and it will not work around a site’s sign-in or a block on your network. It says so when that is the reason.

    Why does Windows warn me when I install it?

    The installers are not code-signed yet, because that needs a paid certificate. Windows SmartScreen shows a warning for any unsigned program. Choose More info, then Run anyway. If you want to be sure the file is the one we published, compare its SHA-256 with the one shown on this page.

    What is the difference between Standard and Full?

    Standard has the downloader, the player and the browser. Full adds a code editor, terminal, source control and an MCP client. The two installers are about the same size to download, because most of the size is the media tools. Standard simply does not contain the editor, so it does not load it or use memory for it.

    Does it run on Mac or Linux?

    Not yet. This release has the Windows installers and the Android app. Linux and macOS builds are on the list, with no date.

    How do I install the Android app?

    Download the APK onto the device, or copy it there from a computer, and open it. If Android asks, allow installs from that source in its settings. From a computer you can also connect the device and run adb install -r lumina-tv-VERSION.apk. The Download section above has the exact file name.

    Where do my files go?

    By default music goes to Music\Lumina, videos to Videos\Lumina and other files to Downloads\Lumina. You can change each folder in Settings. Uninstalling Lumina never deletes them.

    Something doesn’t work. What should I do?

    Open an issue on GitHub and say what you were doing and what you saw. Plain words are fine.
